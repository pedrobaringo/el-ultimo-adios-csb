# El Último Adiós-CSB
 
Tutorial en video: https://youtu.be/Qs6hNqjl93Q

# Instalación
Primero deberás tener instalado el sistema Custom System Builder (https://foundryvtt.com/packages/custom-system-builder) en tu Foundry.

Después necesitarás instalar el módulo de El Último Adiós. Por ahora la única forma es instalandolo copiando el manifest https://github.com/pedrobaringo/el-ultimo-adios-csb/releases/latest/download/module.json 

<img width="930" height="788" alt="image" src="https://github.com/user-attachments/assets/0e6353b8-25f0-4694-be68-20d6a7e1f05b" />

Ahora ya puedes crear un mundo con el sistema Custom System Builder. Activa el módulo del Último Adiós y te saldrá este mensaje en el chat:

<img width="301" height="360" alt="image" src="https://github.com/user-attachments/assets/f98a94a5-2332-4f81-89a7-f6bc7734a012" />

Haz click en el botón Importa los compendios. Se actualizará la página cuando acabe la importación.

# Fichas de personaje
Crea un nuevo actor (no abras las fichas en la carpeta Templates actores).

<img width="610" height="615" alt="image" src="https://github.com/user-attachments/assets/181ff6ab-3925-4429-a25b-200505fbcf54" />

1. Elige que tipo de ficha quieres crear (Personaje jugador o Personaje no jugador).
2. Haz click en el icono de refrescar, seguramente tengas que hacer click dos veces para que se acomode al tamaño correcto.

# Tiradas
Cuando haces click en Física, Mental o Social aparecerá una pantalla donde puedes elegir añadir bonificadores o penalizadores y seleccionar si la tirada es normal, con ventaja o con desventaja.

<img width="403" height="285" alt="image" src="https://github.com/user-attachments/assets/0baa6fe6-312a-488c-935c-ae0158487bfc" />

Si el personaje es un Mensajero el mensaje del chat con la tirada mostrará los dados negros correspondientes al nivel de sombra que tenga y un botón para incrementar la sombra.

<img width="298" height="403" alt="image" src="https://github.com/user-attachments/assets/3e84a3da-b3c4-49e8-aca2-7b2ecc9489a5" />

Si hacemos click en Incrementa la sombra nos pedirá cuantos dados de sombra queremos añadir y se tirarán esos dados y se añadirán a la tirada anterior:

<img width="407" height="151" alt="image" src="https://github.com/user-attachments/assets/7034940b-8f72-45a4-92f5-f94c9a345cee" />

Si el personaje es un Custodio la tirada no tendrá dados de sombra ni botón:

<img width="298" height="275" alt="image" src="https://github.com/user-attachments/assets/c7efa47f-8df2-4554-902a-8d93f7f27a21" />
